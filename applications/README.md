# Applications

Future DUK applications are organized here: `operator-dashboard/` for robot
monitoring, `gateway/` for controlled API/telemetry access, and `mobile/`
for a future mobile interface.

These are **reserved directories**, not running services. Interactive plots
and model debugging belong to core notebooks, not an independent research
dashboard. Hardware actuation and safety-critical controls must remain governed
by the robot control architecture rather than direct app requests.
