# tools

Các chương trình kỹ thuật được duy trì và dùng lại: sinh/chuyển đổi mô hình,
kiểm tra tính nhất quán tham số, kiểm tra điều kiện môi trường.

Mỗi tool được triển khai cần có mục đích, đầu vào/đầu ra, hướng dẫn chạy và
kiểm thử tương ứng. Thư mục có `.gitkeep` hiện chỉ là vị trí quy hoạch.

`scripts/` chỉ giữ script lẻ phục vụ dev; `.github/` quản lý CI/CD.
