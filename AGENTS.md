# DUK Agent Instructions

## Read first

1. Read [README.md](README.md) and the [documentation index](docs/README.md).
2. Consult the [repository layout](docs/architecture/repository-layout.md) for artifact ownership.
3. Read the nearest applicable nested `AGENTS.md`.
4. Inspect existing implementation and approved project decisions before modifying anything.

## Scope

- Respect the agreed folder structure and existing ownership boundaries.
- Do not invent unresolved engineering decisions, physical parameters, interfaces, controller designs or platform capabilities.
- Keep reserved documents as placeholders until their content is established by project work.
- Do not present reserved folders as implemented components.
- Preserve unrelated files and history; avoid duplicate modules, owners or documentation.
- Verify links and paths for documentation changes. Report only checks that were actually run.
- Do not operate real hardware, flash firmware or deploy without explicit authorization.

This file defines agent behavior, not project architecture. Read [CONTRIBUTING.md](CONTRIBUTING.md) for future contribution-process documentation.
