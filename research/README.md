# Research

`research/` reserves the following project areas:

| Directory | Scope |
| --- | --- |
| `experiments/` | Scientific experiments |
| `benchmarks/` | Comparable evaluation cases |
| `publications/` | Papers, theses and research materials |

Interactive engineering notebooks belong to the [robotics core](../robot/software/core/README.md). Research documentation is reserved under [Research](../docs/research/README.md) and [Experiments](../docs/experiments/README.md).
