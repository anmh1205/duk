# Phần cứng DUK

Dữ liệu nguồn đặt tại `robot/hardware/mechanical/` (CAD, drawings và
manufacturing) và `robot/hardware/electronics/` (board, nguồn, dây).
Mô tả dùng cho ROS đặt riêng tại `robot/software/ros2_ws/src/duk_description/`.

Khi cập nhật thiết kế, ghi rõ phiên bản phần cứng, đơn vị và nguồn của
thông số hình học/động lực học. Các bản xuất chế tạo cần mang đúng phiên bản
thiết kế; không thay thế CAD gốc bằng file mesh.
